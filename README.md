# defile

A minimalist modern file manager for Linux.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/Gylmynnn/Defile/main/scripts/install.sh | bash
```

Installs the latest AppImage to `~/.local/opt/defile`, adds the `defile` command to
`~/.local/bin`, and registers it in the application launcher. Requires `curl`,
`mpv` (libmpv), and FUSE (`libfuse2` on Debian/Ubuntu, `fuse2` on Arch).
